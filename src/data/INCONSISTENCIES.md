## 3. Walkthrough "Min. Stats" vs the build-up requirement computed from the FAQ

The walkthrough's _Min. Stats_ are the minimum stats the previous weapon needs before it can build up to this one. The FAQ gives base stats; the requirement is `base − floor(10% of base)` per stat (FAQ section 4.5). Attack and the eight element stats compared (the walkthrough's second column, apparently durability, is ignored).

- 107 weapons compared; 50 differ in at least one stat.

Many of these look like column shifts in the walkthrough's table (the values are right but sit one stat to the side, e.g. Smash Wrench: Flame 0 / Chill 9 / Lightning 0 / Cyclone 18 / Smash 0 instead of Flame 18 / Chill 0 / Lightning 9 / Cyclone 0 / Smash 18). The app does not use these numbers; it computes requirements from the FAQ's base stats.
